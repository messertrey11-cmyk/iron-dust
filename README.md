# Iron Dust — Frontier Rail Run
Solo: double-click index.html (offline lobby + solo runs).
Co-op: run start-game.bat (Windows) / start-game.command (Mac) / start-game.sh (Linux) — needs Node.js — then friends open http://<your-ip>:8080.
Rebuild client after editing js/main.js or js/models.js: npm install && npm run build
All art/sound is procedural code. three.js (MIT).
